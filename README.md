# Evento Cultural

Bienvenido al repositorio del proyecto **Evento Cultural**. Este es un sistema/plataforma diseñado para la gestión, promoción y acreditación de eventos culturales.

## 🚀 Características Principales

- **Gestión de Eventos:** Creación, edición y visualización de eventos artísticos, musicales, teatrales y literarios.
- **Acreditación Rápida:** Sistema integrado para el registro de asistentes y escaneo de accesos.
- **Calendario Interactivo:** Vista mensual y semanal de las actividades programadas.
- **Notificaciones:** Alertas automáticas para usuarios registrados sobre cambios de horario o nuevos eventos.

## 🛠️ Tecnologías y Herramientas

Este proyecto está construido utilizando tecnologías modernas de desarrollo web:

- **Frontend:** HTML5, CSS3 (con variables personalizadas y diseño premium), JavaScript (ES6+).
- **Control de Versiones:** Git y GitHub.

## 📦 Instalación y Configuración

Para ejecutar este proyecto de forma local, sigue estos pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/sergiogimenezclass/evento-cultural.git
   cd evento-cultural
   ```

2. **Abrir en tu navegador:**
   Puedes abrir el archivo `index.html` directamente en tu navegador o utilizar una extensión como *Live Server* en VS Code.
